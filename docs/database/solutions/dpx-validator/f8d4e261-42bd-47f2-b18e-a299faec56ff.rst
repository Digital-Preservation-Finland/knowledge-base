Analyses
--------

Data is not marked unencrypted
==============================

Data is and must be unencrypted.

Metadata field for encryption in the DPX file header is not set to indicate unencrypted content or the value in the field is set incorrectly.

The value should be FFFFFFFF like described in https://github.com/Digital-Preservation-Finland/dpx-validator/blob/v1.0.2/dpx_validator/dpx_validator.py#L58.

Is it a bug in the validating software? - no
